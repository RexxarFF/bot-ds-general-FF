# FunFernus Platform — обновление 08.08.2026

Это обновление рассчитано на PHP 8.3 и общую MySQL/MariaDB сайта + Minecraft-плагина.
Сайт использует `private/funfernus/config.php`. `.env` для сайта не нужен.

## Перед обновлением

1. Сделайте резервную копию папки сайта и базы данных.
2. НЕ удаляйте ваш рабочий `/private/funfernus/config.php` — в релизе реального config.php нет.
3. Остановите Minecraft-сервер перед заменой JAR плагина.

## 1. Сайт

Распакуйте `FunFernus-Site-20260808.zip` в корень файлового аккаунта так, чтобы файлы из `www/funfernus.ru/` заменили одноимённые файлы сайта.

Ваш `/private/funfernus/config.php` оставьте существующим. В пакете есть только `config.example.php`.

После загрузки сделайте жёсткое обновление страницы браузера (Ctrl+F5), чтобы обновились `auth.js`, `platform.js` и `platform.css`.

## 2. База данных

`app/bootstrap.php` умеет безопасно создавать/добавлять необходимые таблицы и поля автоматически.

Для явного обновления можно один раз выполнить в phpMyAdmin:

`database/update-20260808.sql`

На чистой базе используйте `database/schema.sql`.

## 3. Minecraft-плагин

Замените старый FunFernusBank JAR на:

`FunFernusBank-3.3.2-platform.jar`

Одновременно должен лежать только один JAR FunFernusBank.

Версия 3.3.2 сохраняет интеграцию с NobleWhitelist и больше не считает простое нахождение в whitelist фактом первого входа. Игрок появляется в статистике сайта только после реального входа на сервер.

## 4. Discord-бот

Распакуйте `FunFernusBot-20260808.zip` поверх текущего общего бота, сохранив ваши рабочие токены/секреты/настройки.

Website Bridge теперь обрабатывает:
- публичную заявку на сервер;
- заявку на город;
- заявку на бизнес с выбранным банковским счётом;
- техподдержку;
- обратное решение/ответ на сайт.

## 5. Как выдать админку аккаунту

После регистрации нужного пользователя выполните в MySQL:

```sql
UPDATE users
SET is_admin = 1
WHERE minecraft_username = 'ВАШ_НИК';
```

При следующем обращении к сайту встроенная роль `Администратор` назначится автоматически. Она имеет системное право `*` и отображается как неоновая роль в профиле/статистике.

Дальше роли и права можно создавать уже через `/admin.php`.

## Основные изменения

- Главная: заметная жёлтая кнопка входа; после авторизации — аватар; на телефоне вход/профиль только внутри прежнего меню.
- «Подать анкету» открывает модальное окно с вопросами старого Discord-бота.
- Профиль: друзья/подписки внутри профиля, модальная конфиденциальность, техподдержка, неоновые роли.
- Мессенджер: исправлены сообщения, изображения, Enter/Shift+Enter, глобальный чат, каналы, контекстное меню, mute/block/clear/pin, счётчик 99+.
- Сообщения не попадают в глобальный колокольчик; новые ЛС дают отдельный toast.
- Банк и бизнесы объединены. Бизнес создаётся заявкой и привязывается к выбранному счёту.
- Бизнес: график доходов/расходов/результата и управление финансами.
- Статистика: баннеры зарегистрированных игроков, Minecraft-головы, роли, показываются только реально заходившие на сервер игроки.
- Города: расширенная заявка, координаты, баннер, роли/права, казна и управление.
- Админ-панель: пользователи, роли/права, баланс, верификация городов/бизнесов, глобальный чат, модерация, поддержка, аудит.
- Все новые платформенные страницы используют общий фон/частицы и адаптированы под мобильные экраны.
